# Activation Plan

SeedTag Studio is live as a free plant sale and seed swap kit. Revenue activation is intentionally off until the owner creates payment, sponsor, or service accounts.

## Fastest Revenue Switch: Club Template Pack

Estimated owner time: 20-30 minutes.

1. Create a ZIP named `seedtag-studio-club-pack.zip` containing printable sponsor sign examples, seasonal label art, starter CSV files, and a setup checklist.
2. Go to Gumroad, Payhip, or Ko-fi Shop.
3. Create a digital product titled `SeedTag Studio Garden Club Pack`.
4. Suggested pricing: pay-what-you-want with `$9` suggested, or fixed `$19`.
5. Paste this product description:

   ```text
   A garden club add-on pack for SeedTag Studio with starter CSVs, sponsor-ready table signs, volunteer print checklists, and seasonal label layouts. The SeedTag Studio web app stays free and no-login.
   ```

6. Upload the ZIP and publish.
7. Add the product URL to `README.md` under the live demo link:

   ```md
   Optional garden club template pack: <YOUR_PRODUCT_URL>
   ```

8. Commit, push, and wait for GitHub Pages to redeploy.

## Service Offer Switch

Estimated owner time: 15-20 minutes.

1. Create a simple service listing on Ko-fi Commissions, Gumroad, or the owner's existing site.
2. Title it `SeedTag Studio Club Setup`.
3. Suggested offer:

   ```text
   I will turn your garden club's crop spreadsheet into a SeedTag Studio-ready CSV/JSON starter file and print checklist.
   ```

4. Suggested price: `$49` for one club event.
5. Add the service link to `README.md` and a launch post only after the payment page is active.

## Pro / Plus Feature Location

SeedTag Plus should be sold as event packs and setup services. Good paid additions:

- Region-specific crop starter CSVs.
- Native plant sale care-card pack.
- Sponsor-ready fundraiser sign templates.
- Done-for-you CSV cleanup for clubs.

## First Use Flow

1. Open the sample event.
2. Change the last frost date and sale date.
3. Add three starter crops from the library.
4. Edit one price or donation field.
5. Print a plant tag grid preview.
6. Download the ICS calendar and CSV backup.

## Success Signals

- A volunteer can print labels from sample data in one session.
- CSV and JSON import/export work without accounts.
- Garden clubs understand that crop timing defaults should be adjusted locally.
