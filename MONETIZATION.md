# Monetization

SeedTag Studio should remain useful as a free static app. Revenue options should support clubs and libraries without adding paid runtime services.

## Practical Offers

- Printable premium packs: seasonal label art, sponsor-ready sale signs, and workshop worksheets.
- Club setup package: one-time fee to customize crop defaults, logo placement, and print sizes.
- Local sponsor bundle: table sign footer placement for nurseries, tool libraries, or cooperative extensions.
- Donation prompt: link to the host club's existing donation page in exported signs or README docs.
- Training workshop: paid session for volunteers before spring plant sale season.

## Boundaries

- Do not require accounts for core label generation.
- Do not send plant, event, or contact data to a third-party service.
- Do not monetize by adding invasive plant recommendations or regionally unsafe advice.
- Keep CSV/JSON exports open so clubs can leave at any time.

## Plus Feature

SeedTag Plus should live as paid event packs and setup services. The free app should keep all core label generation, imports/exports, ICS, and print layouts.

Good Plus additions:

- Region-specific starter CSVs.
- Native plant care-card packs.
- Sponsor-ready fundraiser signage.
- Done-for-you club spreadsheet cleanup.
