# LinkedIn Launch Copy

I built SeedTag Studio for garden clubs, seed libraries, and plant sale volunteers.

It turns one crop batch into printable plant tags, seed packet labels, care cards, table signs, and a frost-date task calendar. It runs as a static web app, supports CSV/JSON import/export, and does not rely on paid APIs or external services.

Demo: https://huslayer826.github.io/seedtag-studio/
