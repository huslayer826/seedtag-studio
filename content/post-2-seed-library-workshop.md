# Post Draft: Seed Library Workshop Kit

Seed libraries need labels that are short, useful, and consistent. SeedTag Studio helps volunteers turn a crop list into seed packet label sheets with spacing, sun, water, maturity, and sowing notes.

Use it during a packaging night: import a CSV, clean up the care notes, print packet labels, then export JSON so next season starts from the same batch.

The app is static, runs in the browser, and does not require paid APIs or external services.
